# PT Limawira Wisesa — Marketing Site

Hugo + Decap CMS + Tailwind CSS v4 website for PT Limawira Wisesa, an
Indonesian system integrator specialising in enterprise digital
infrastructure and critical power solutions.

> **Full documentation:** see [AGENTS.md](./AGENTS.md) for the build
> pipeline, content editing guide, conventions, and troubleshooting.
>
> **TL;DR:**
> ```bash
> yarn install
> yarn start         # dev server on http://localhost:3000
> yarn build         # production build → ./dist
> ```

The CMS lives at **`/admin/`** on the live site.
