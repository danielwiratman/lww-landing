# Customer logos (placeholder images)

These are placeholder logo images extracted from the source Word document
(`resources/Kelengkapan Untuk Website LWW_files/`). They are not in any
particular order and many of them may be unused. The Decap CMS will
expose them as selectable options when an editor uploads a logo for a
**customer**, **partner**, or **solution** record.

## How to use

1. Open `/admin/`, log in with Netlify Identity.
2. Navigate to the relevant collection (e.g. **Solutions → UPS Solution**).
3. For each entry under **Selected customers**, click the image picker
   and select a logo from the **Customers** folder.
4. The picker can also be used to upload a new, high-quality replacement
   logo — these placeholder files can then be deleted.

## When the real logos are ready

Drop the final PNG/SVG logos into this folder, then update the customer
records in the CMS to reference them. The placeholder `image001.png` …
`image080.png/jpg` files can be removed once they are no longer
referenced anywhere.
